นำเข้าข้อมูลสินค้า & กฎ Shelf life

ลากไฟล์ Excel (.xlsx / .xls), CSV, PDF หรือรูปภาพ (ถ่ายรูปรายงาน/ตาราง) ของรายการสินค้ามาวาง ระบบจับคู่ด้วยรหัส (SKU) หรือชื่อสินค้า — รายการที่มีอยู่แล้วจะอัปเดตให้เป็นล่าสุด รายการใหม่จะเพิ่มให้ ช่องที่เว้นว่างในไฟล์จะไม่ทับข้อมูลเดิม ถ้าเปลี่ยน Shelf life แต่ไม่ได้ใส่วันลดราคา ระบบคำนวณกฎให้ใหม่ตามคู่มือ

ลากไฟล์มาวางที่นี่หรือ คอลัมน์ที่อ่านได้: ชื่อสินค้า · SKU · ประเภท (นำเข้า/ท้องถิ่น) · อุณหภูมิ · Shelf life · วันลด 15% / 30% · วัน Code 52 · Buyer UID · Commercial UID

เพิ่มรายการ OOS

ถ่ายหรือแนบรูปได้ — ระบบย่อรูปให้อัตโนมัติ และทุกคนในทีมเห็นรูปเดียวกัน

นำเข้ารายงาน OOS

ลากไฟล์ Excel (.xlsx / .xls) หรือ CSV ของรายงานสินค้าหมดชั้น / หมดสต็อกมาวาง ระบบอ่านคอลัมน์ Item No (บังคับ) และ ชื่อสินค้า · ตำแหน่ง · สต็อก · วันที่/เวลา · ผู้รับผิดชอบ · หมายเหตุ (ถ้ามี) — รายการที่ยังเปิดอยู่จะไม่ซ้ำ รายการที่เคยเติมแล้วแต่กลับมาอยู่ในรายงานจะเปิดใหม่ ตำแหน่งชั้นและชื่อที่ขาดจะเติมจาก Makro Finder ให้

ลากไฟล์มาวางที่นี่หรือ

ทะเบียนสินค้า (Barcode.csv) → Class / Buyer

เลือกไฟล์ทะเบียนสินค้าที่มีคอลัมน์ Dept no · Art Grp No · Art Grp Sub No · Barcode · Art No แอปอ่านไฟล์ในเครื่องนี้ ไม่อัปโหลดขึ้นเว็บ แล้วเติม เลข Class (Art Grp No) ให้ Item NBS ตามเลข Item และหา Buyer จากกฎ Class → Buyer (ไม่ทับ Buyer ที่ตั้งไว้แล้ว และไม่เดาถ้า Class นั้นมีหลาย Buyer)

ลากไฟล์ Barcode.csv มาวางที่นี่หรือ ไฟล์ใหญ่ (ประมาณ 11 MB) ใช้เวลาอ่านไม่กี่วินาที

นำเข้ากฎ Buyer (Class → Buyer)

ลากไฟล์ Excel / CSV ที่มีคอลัมน์ Division · Dept · Class · buyer_uid · Buyer Name มาวาง ระบบเขียนเลข Class ที่แต่ละ Buyer ดูแลลงช่อง “สินค้าที่ดูแล” ของ Buyer คนนั้น (เลข Class = เลข Art Grp) แล้ว Item NBS ที่มี Art Grp จะได้ Buyer เองอัตโนมัติ · แถวที่เหมือนกันทุกช่องนับเป็น 1 กฎ ไฟล์ใหญ่หลักแสนแถวก็ใช้ได้ · Class ที่มีหลาย Buyer ระบบจะไม่เดา

ลากไฟล์มาวางที่นี่หรือ คอลัมน์ที่อ่านได้: Division · Dept · Class · buyer_uid · Buyer Name

นำเข้าตาราง Item → Art Grp

ลากไฟล์ Excel (.xlsx / .xls), CSV, PDF หรือรูปภาพของตารางที่มีเลข Item คู่กับ Art Grp มาวาง ระบบใส่ Art Grp ให้ Item NBS ที่เลข Item ตรงกัน แล้วกำหนด Buyer ให้ตามเลข Art Grp ที่ Buyer ดูแล (ใน Buyer / Commercial) · ถ้าไฟล์ไม่มีหัวคอลัมน์ ให้เรียงคอลัมน์แรก = Item คอลัมน์ที่สอง = Art Grp

ลากไฟล์มาวางที่นี่หรือ คอลัมน์ที่อ่านได้: Item No · Art Grp (No.) หรือ Class (เช่น "681 Cereal Milk") · ชื่อ Art Grp (ไม่บังคับ)

นำเข้ารายชื่อ Buyer / Commercial

ลากไฟล์ Excel (.xlsx / .xls), CSV, PDF หรือรูปภาพ (ถ่ายรูปรายงาน/ตาราง) ของรายชื่อผู้ติดต่อมาวาง ระบบจับคู่ด้วย UID — UID ที่มีอยู่แล้วจะอัปเดตข้อมูลให้เป็นล่าสุด UID ใหม่จะเพิ่มให้ ช่องที่เว้นว่างในไฟล์จะไม่ทับข้อมูลเดิม

ลากไฟล์มาวางที่นี่หรือ คอลัมน์ที่อ่านได้: UID · ชื่อ · บทบาท · กลุ่ม · แผนก/หมวด · โทร · อีเมล/LINE · ผู้ติดต่อสำรอง

นำเข้าข้อมูล Item NBS

ลากไฟล์ Excel (.xlsx / .xls), CSV, PDF หรือรูปภาพ (ถ่ายรูปรายงาน/ตาราง) ของรายงานสินค้าที่ไม่มียอดขายมาวาง ระบบอ่านคอลัมน์ให้เอง แยกกลุ่ม FF / DF / NF คำนวณจำนวนวันที่ไม่มียอดขาย และเริ่มเฝ้าระวังให้อัตโนมัติ

ลากไฟล์มาวางที่นี่ หรือ

ถ้าไฟล์มีคอลัมน์ Division ระบบใช้ตามนั้น 100% (FRESH FOOD = FF · DRY FOOD = DF · NON FOOD = NF) ถ้าไม่มี จะเดาจาก: ชื่อชีต → ชื่อไฟล์ → ค่านี้
